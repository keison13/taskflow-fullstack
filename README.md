# taskflow-fullstack
TaskFlow é uma aplicação web Full-Stack completa para gerenciamento de projetos e tarefas. A aplicação conta com um backend em Node.js (Express, TypeScript e Prisma ORM) integrado a um banco de dados PostgreSQL (Neon), e um frontend construído em Next.js. O sistema permite criar e acompanhar o progresso de múltiplos workspaces em tempo real.
